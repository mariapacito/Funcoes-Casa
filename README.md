# Atividade - Funções e Testes

## Descrição
Atividade desenvolvida para praticar a criação de funções em JavaScript e a realização de testes automatizados utilizando testes unitários.

## Funções desenvolvidas

- **par(n):** Verifica se um número é par, retornando `true` ou `false`.
- **media(notas):** Calcula a média aritmética de um array de notas.
- **filtrarMaiores18(usuarios):** Filtra uma lista de usuários, retornando apenas aqueles com idade maior ou igual a 18 anos.

## Testes
Foram realizados testes para verificar o funcionamento das três funções, incluindo casos especiais, como o número zero, array vazio e idade igual a 18 anos.

## Como executar

1. Instale as dependências:

```bash
npm install
```

2. Execute os testes:

```bash
npm test
```
